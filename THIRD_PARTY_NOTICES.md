# Third-party notices

Icon artwork used by the Rad status HUD views (`deploy/PrismaUI_F4/views/Interface/FalloutAnomaly/`).

## Tabler Icons

Tabler Icons — https://tabler.io/icons — version 3.49.0.

Icon outline path data from Tabler Icons is included inline in `hud_needs.html`,
`hud_filter.html`, `hud_climate.html` and `hud_toxic.html`:

- `apple`, `droplet`, `moon` (needs)
- `lungs`, `filter`, `mask` (breathing protection)
- `temperature`, `thermometer`, `wind` (climate)
- `heart`, `bolt`, `radioactive`, `virus` (vitals)
